Format Information

AIKEN Format

The AIKEN format is a simple text format for multiple choice questions. Each question starts with a number, followed by the question text, then options A-D, and finally the correct answer.

Example: 
1. What is the capital of France?
A. London
B. Berlin
C. Paris
D. Madrid
ANSWER: C
GIFT Format

GIFT (General Import Format Template) is Moodle's format for importing questions. It supports multiple question types and rich formatting options.

Example: 
::Geography::What is the capital of France? {
~London
~Berlin
=Paris
~Madrid
}
